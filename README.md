# Stoplight App

An application used to display a stoplight. 

## Frameworks

- **Next.js 16** 
- **React 19** 
- **Chakra UI 3** 
- **TypeScript** 
- **Emotion** 

## Running the App

1. Run the development server:
```bash
npm run dev
```

2. Open [http://localhost:3000](http://localhost:3000) in your browser.
